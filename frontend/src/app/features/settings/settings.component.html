GitHub-token

Vad tokenen kan

Tokenen behövs bara i Redigeringsläget, för att spara courses.json i ditt data-repo. Spelläget fungerar utan token.

Skapa en fine-grained personal access token med minsta möjliga behörighet:

  • Repository access: Only select repositories — välj endast data-repot.
  • Permissions: Contents: Read and write (contents:write). Inga andra behörigheter.

Tokenen sparas endast i den här webbläsarens localStorage och skickas bara till GitHub. Den kan inte läsa eller ändra något annat än data-repot.

Så återkallar du den

  1. Tryck på Radera token nedan för att ta bort den från den här webbläsaren.
  2. Återkalla den helt hos GitHub under Settings → Developer settings → Fine-grained tokens: välj tokenen och tryck Delete.
